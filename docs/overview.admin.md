## What it does

API lets approved external systems read or update site data in a controlled way, so other software can connect to your site.

## Do I need to do anything?

Usually no. It works behind the scenes once installed and configured. You will see its effect when a connected system exchanges data with your site.

## Where it shows up

It does not add a day-to-day screen. Its effect appears in connected systems that read or send data.

## Good to know

- This connects other software to your site, so leave its setup to someone who manages integrations.
- Ask your developer before granting a new system access.
